# Bugs and Features

A repository just for bugs and feature requests.

Put them into issues and tag them with the appropriate type. 

Upvote with 👍 to score them.
If you manage to repro a bug, post a reply to the issue - it will help us resolve it faster. The more details, the better.

With bugs, please include any console logs with errors, crash logs, etc. The more verbose the better!
